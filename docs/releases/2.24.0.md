# Manager 2.24.0

Manager now opens in a clean, colorful light appearance. The appearance switcher
offers Light, Dark and System modes and remembers your choice in this browser.
Status badges, navigation, configuration editors and logs follow the chosen theme.

Persistent workspace tabs make it easier to move between servers, projects,
applications and deployment releases. The workspace bar shows the current server
and application context, supports closing tabs and keyboard navigation, and
restores recent tabs after a refresh. Choosing a server can resume your last
location on that server. The existing sidebar and application section navigation
remain familiar, with a compact layout on smaller screens.

Workspace history is scoped to your signed-in account and role in this browser,
limited to 20 tabs, and checked against available servers. It stores approved
navigation locations and labels, never application configuration values or
credentials. Environment and application settings warn before workspace navigation
discards unsaved changes. Workspace history does not synchronize between devices.

## Update

From Manager 2.21.0 or newer, open **Settings → Manager updates**, download and
install 2.24.0. Offline installations can import the matching signed Node.js 22 or
24 update package. The updater briefly restarts Manager, keeps hosted applications
running and retains the previous version plus database/configuration backups.

## Validation

The local suite passed 437 tests with 12 optional integration tests skipped. The
production build and focused navigation tests passed. Browser checks covered
theme switching, workspace restoration, server switching, unsaved settings and
narrow screen layouts. GitHub repeats the tests and production build before
publishing signed release packages.
