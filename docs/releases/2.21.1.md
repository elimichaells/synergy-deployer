# Manager 2.21.1

Fixes Linux SSH setup failing with `useradd: command not found` after downloading
its tools. The installer now preserves the standard system administration paths
needed for account creation and agent enrollment.

Real OpenSSH installation, enrollment, monitoring, credential handling, temporary
file cleanup and service restart checks passed on disposable Windows Server 2025
and Ubuntu 24.04 machines. The repository includes a repeatable **SSH onboarding
lab** workflow; no separate test servers or production credentials are needed.

## Update an existing Manager

From Manager 2.21.0, open **Settings → Manager updates**, check for updates, then
download and install 2.21.1. For an offline installation, import the matching
`manager-update-win32-x64-node22.tar` or `manager-update-win32-x64-node24.tar`.
Packages include GitHub/Sigstore build signatures verified by the updater.

The update briefly restarts Manager and its dashboard helpers. Hosted applications
keep running. The previous release and a database/configuration backup remain
available for recovery.

Managers older than 2.21.0 must first use the one-time bootstrap from the
[2.21.0 release](https://github.com/elimichaells/synergy-deployer/releases/tag/v2.21.0),
then install this update. This release does not change SSH requirements: the
target needs reachable SSH/SFTP and administrator or root/sudo access.
