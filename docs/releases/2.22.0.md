# Manager 2.22.0

Manager now starts with a server chooser. Select **Manager host** for the local
workspace, or a connected Windows or Linux server for its applications,
deployments and monitoring. Switch servers from the header, search by name,
location or address, or return to the last server you visited. Pending servers
open their SSH setup. Navigation follows the selected server and unavailable
servers show an error without displaying another server's data.

Server cards are compact rectangles: two per row on medium screens and three on
wide screens, with status, operating system, location and app count kept visible.

Application creation now offers **Production only**, **Staging only**, and
**Production + Staging**. Staging only creates a single independent app with its
own branch, port, setup, database configuration, domain and webhook settings.
Projects containing only staging apps open directly in Staging. App counts and
project membership include standalone staging; promotion is shown only when a
production counterpart exists. Existing applications and API clients retain
their environment configuration.

## Update an existing Manager

From Manager 2.21.0 or newer, open **Settings → Manager updates**, check for
updates, then download and install 2.22.0. Offline installations can import the
matching `manager-update-win32-x64-node22.tar` or
`manager-update-win32-x64-node24.tar`. Packages carry GitHub/Sigstore build
signatures verified by the updater, including when imported offline.

The update briefly restarts Manager and its dashboard helpers. Hosted
applications keep running. The previous release and a database/configuration
backup remain available for recovery.

Managers older than 2.21.0 must first use the one-time bootstrap from the
[2.21.0 release](https://github.com/elimichaells/synergy-deployer/releases/tag/v2.21.0),
then install this update. Existing Linux SSH fixes are included.
