# Manager 2.29.1

Administrators can rename remote servers from the server directory, server connections page, Overview or Agent access page. Pending, online, offline and revoked connections are supported. The new display name appears in the server selector, workspace navigation and removal confirmation.

Renaming changes only the name shown in Manager. The server ID, operating-system hostname, SSH connection, agent enrollment, applications, services and domains retain their existing configuration. No agent update is required.

Names must contain 1–100 characters after trimming whitespace and cannot contain control characters. Renaming requires an administrator and a same-origin request, is paused during Manager updates, and is recorded in the audit log. A stale edit cannot overwrite another administrator's rename; an older removal confirmation is also invalidated by a name change.
