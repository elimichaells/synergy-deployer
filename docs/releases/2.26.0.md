# Manager 2.26.0

The Manager host and connected Windows and Linux servers now share the same
workspace components: overview, navigation, project and application cards,
repository import, environment choices, application tabs, release details,
deployment history, build logs, and infrastructure navigation. Compact persistent
tabs retain the selected server, application, environment, and individual release.
Requests remain scoped to the selected server and navigation protects unsaved work.

App creation supports production only, staging only, or both environments, followed
by framework detection and the existing guided runtime, database, environment,
domain, and deployment setup. Remote process status remains distinct from HTTP
readiness. Remote agents do not yet provide streaming runtime logs or an interactive
console; these limitations are stated in the shared application tabs.

## Safe remote agent updates

Infrastructure > Agent access & updates shows the installed and available agent
versions. Administrators can queue an update from the Manager. A stable supervisor
waits for active deployment work, validates the staged agent, checks fresh
heartbeats and application state, and automatically restores the previous agent
if verification fails. Durable recovery handles interrupted activation.

Agent updates preserve server enrollment, application files, database state,
Caddy configuration, and running application processes. The Manager supplies the
agent bundle over its authenticated connection, so remote servers do not need
GitHub or internet access. Installing an offline Manager package also supplies
the bundled agent update.

New SSH installations include agent 1.2.0 and its supervisor. Older installations
show a one-time migration guide using their existing service account and data
directory. Updating Manager does not automatically upgrade remote agents, and
the supervisor itself is outside the agent update protocol.

## Manager installation and recovery

Managers on 2.21.0 or newer can install the signed release through Settings >
Manager updates or import the matching Node.js 22/24 package offline. The updater
retains the previous release and database/configuration backups. Hosted
applications remain running during the Manager update. Schema migration 027 adds
remote agent update tracking without changing application data.

and the production build passed. Windows/Linux compatibility checks passed on
Node.js 22 and 24, together with SSH and PostgreSQL integration checks. Isolated
desktop/mobile previews covered shared host/remote screens, server switching,
